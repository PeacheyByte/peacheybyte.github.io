# The Collection Curator — User Guide

Welcome to the official user guide for **The Collection Curator**. This guide walks you through setting up your inventory, organizing items by locations and tags, tracking financials, and exporting records.

---

### **Getting Started**

1. **Adding Your First Item**  
   Tap the **+** button on the main screen to create a new record. Add a photo, item title, purchase price, current location, and any relevant tags.

2. **Organizing by Locations & Tags**  
   Assign storage boxes, shelves, or rooms as locations so you always know where physical items sit. Use tags to group items by type, condition, or sale status.

3. **Tracking Sales & Profit**  
   When an item sells, mark it as sold and input the final sale price. The Collection Curator will calculate your net profit automatically.

4. **Backing Up & Exporting**  
   Export your database to a standard CSV file anytime to create local backups or open your inventory in spreadsheet applications like Microsoft Excel.
